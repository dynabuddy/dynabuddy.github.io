Security Measures

Safe by keeping less.

Last updated November 13, 2026

The short version. The safest data is data nobody else holds. DynaBuddy keeps your things on your computer, has no server and no account to break into, and checks its Mac updates before installing them. Here is what that means, and what it doesn't cover.

Your data stays with you

  • Notes, files, chat history, memories and settings are stored locally on your computer.
  • API keys you add are stored locally. They are used only to talk to the providers you chose, and never sent to DynaBuddy.
  • There is no DynaBuddy account or server, so there's no central store of user data to leak.
  • No analytics and no crash reporting. Nothing is collected beyond the daily update check.
  • Speech recognition, the writing check and transcription run on your device.

Updates you can trust

  • Installed copies check this site once a day and download updates from the official GitHub Releases page.
  • On Mac, every update is listed with its SHA-256 checksum and a signature, and is checked against DynaBuddy's own signing key before it installs. An update that fails the check is not installed.
  • The signing-key check described here applies to Mac updates. Windows is in beta and updates from the same release page.

Installing safely

DynaBuddy is free and is made without paid developer certificates, so macOS and Windows warn you the first time you open it. That warning is expected. To stay safe, get DynaBuddy only from the download buttons on dynabuddy.github.io or the official releases page. GitHub shows a SHA-256 checksum next to each file there, so you can compare it with your download.

Permissions, used narrowly

DynaBuddy may ask for permissions such as Accessibility, microphone, screen recording and folder access. It uses each one only for the tool you're using. You can turn any of them off in your system settings at any time, and the matching tool will stop working until you turn it back on.

What we can't promise

  • Anything you send to an AI provider is handled under that provider's rules and security, not ours.
  • Your computer's own security matters. Anyone with access to your account or device can reach what DynaBuddy stores there, so keep your system updated and protected.
  • No software is perfect. DynaBuddy is provided as-is, as described in the Terms.

Found a problem?

Please tell the developer through the Threads profile. Say what you found and how to repeat it, and please don't post the details publicly until it's fixed. Fixes ship as updates.
